# GPThost Exports

This directory contains React snippets generated from design analysis files.

## Deployment Instructions

1.  Use the `manifest.json` file to batch deploy these snippets.
2.  Each snippet is a standalone HTML fragment containing React, ReactDOM, Babel, and Tailwind CSS.
3.  The `websiteName` field in the manifest is optimized for subdomain usage (lowercase, hyphens only).

## Snippets

See `gpthost_exports/snippets/` for the generated HTML files.
